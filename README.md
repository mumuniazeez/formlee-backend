# Formlee Backend

Formlee is an form submission delivery system that allows you too receive submission from forms.

This Repository contains the backend code for this project..

## Features

This backend API comes with these features

- Authentication
- User Account Management
- Form CRUD Management
- Form Submission Handling*

## Tech Stack Used

- NodeJS
- NestJS
- PostgreSQL
- Prisma ORM
- Docker

## Contribute to this project

Feel free to raise an issue or create a PR.

### Environment Variable

For environment variables, a sample is added at `.env.example`, any new environment variable must be added to this file

### Usage

To run this project locally on your computer, follow these steps:

1.  Clone the repo

    ```bash
    git clone https://github.com/mumuniazeez/formlee-backend.git

    cd formlee-backend
    ```

2.  Install all the dependencies

    ```bash
    pnpm install
    ```

    Feel free to use any package manager of your choice

3.  Run the project

    ```bash
    pnpm start:dev

    ```
